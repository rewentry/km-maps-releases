# KM Maps — сборки и обновления

Публичный канал Android- и Windows-сборок KM Maps. Данные аккаунтов, метки и фотографии пользователей здесь не хранятся.

## Скачать

[Последний опубликованный релиз](https://github.com/rewentry/km-maps-releases/releases/latest)

- Android ARM64 / эмулятор x86_64: KM-Maps-android-arm64-x86_64.apk. Устанавливайте поверх прежней совместимой сборки, без удаления приложения и очистки данных. Это отладочный канал.
- Windows 10 (1809+) / Windows 11, x64: KM-Maps-windows-x64.zip. Распакуйте архив целиком и запустите KMMaps.exe. Qt отдельно устанавливать не требуется.

**Windows пока является технической предварительной версией:** карта, поиск и локальные метки на основе Organic Maps. Аккаунты KM Maps, группы, сообщества и синхронизация Android ещё не перенесены.

## Обновления

Начиная со сборки 2026.10.23.1 приложения проверяют этот канал при запуске и вручную. Загрузка и установка требуют согласия пользователя. Проверяются версия, размер, SHA-256 и источник; Android дополнительно проверяет пакет, архитектуру и подпись APK.

Первую сборку с механизмом обновления нужно один раз установить обычным способом поверх прежней. Старые версии без этого кода не могут обновиться самостоятельно. Android использует системный установщик с подтверждением.

Windows хранит карты и основные настройки отдельно: %LOCALAPPDATA%\KMMaps\UserData. Обновление создаёт новую папку версии; прежние версии не удаляются.

## Ограничения тестового канала

Android APK подписан прежним debug-сертификатом проекта; он не является защищённой production-подписью. Windows-сборка не имеет коммерческой Authenticode-подписи. Не отключайте системную защиту ради запуска.

Полный переход между двумя опубликованными версиями и визуальный аудит Windows ещё требуют проверки. Детали и контрольные суммы приведены в описании релиза.

## Лицензии

Основа — [Organic Maps](https://github.com/organicmaps/organicmaps). Уведомления и лицензии компонентов включены в дистрибутивы. Qt в Windows динамически связан; [исходники Qt 6.10.0](https://download.qt.io/official_releases/qt/6.10/6.10.0/submodules/).
